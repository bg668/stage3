# 发现优先的报告与上游引用、条件复核

2026-10-27 已实施。范围是已有第三阶段与独立 report-html 链路，不接入 harness2，不调用项目分析模型。

## 变更

1. 公共证据契约及 EvidenceRef 字段说明统一为 F-XXXX Lx[-Ly]；依赖事实复用原始源码位置。完整和部分结果的 artifact 交接补上证据位置，严格解析器及合并保护保持原样。
2. 新增 `harnesses/baseline-v1/skills/control-flow-conditions/SKILL.md`，在 Analyzer 和 Reviewer 的显式位置确定性加载；从调用点区分外层分支、循环、调用成功和结果消费条件。Reviser 角色正文、已有 packet-fact-boundary 技能均未修改。
3. 报告输入将历史问题标为 historical_gaps，按函数合并跨包源码范围；complete 仅表示已提供范围完整，不表示语义已闭合。报告角色以发现和目的聚类为主，全部行为仍有正文实质表达，辅助细节压缩，补料请求不作为默认内容。
4. 报告专用 SelectedGap 增加 text，以短说明表达真正影响恶意判定、关联或处置的当前限制，不直接展示历史 question；没有重要限制时 gaps 可以为空。新增可选 ioc_notes，只表达用途/关联价值，IOC 类型、原值及分流继续由程序绑定，不自动拼接原始含义与证据清单。
5. HTML skill 强化内容选型：短属性用于比较，机制用文字解释，关键代码按需选择；不将长字段机械放入表格，不重复展开同一事实。模型自写正文和绑定的说明字段均检查内部来源包编号，原始对象值与源码不改写。

- 修改前完整离线基线：398 passed / 1 skipped。
- 新增用例先复现 12 个失败、4 个已存在保护通过；修改后 16 项全部通过。首次 artifact 交接测试误用了共享 EvidenceRef，已在测试中复制对象后分别设置位置；没有因此改动生产行为。
