# HTML 报告接入 malware-report-html 1.1

2026-10-29 已实施。基于用户批准的方案；停止运行时自动填入测试资料，无哈希时显示真实空状态。调查与全局事实 schema 保持 11.0。

## 实施结果

- 模板升级至 1.1，接入新版 CSS、渲染器、校验器和 tier_rules.json。内部 skill 为 1.2，报告角色为 1.3；组件、模块说明和规则资源均纳入加载说明、快照与指纹。
- ReportComposition 新增必填 title/findings，chain 支持 brief；发现的档位来自规则表，状态与证据从引用事实生成。普通规则不能覆盖档位，CUSTOM 提示人工复核。
- partial 发现关联对应行为缺口，lead/unclassified 不升级为能力；缺口支持已有历史问题或行为引用。规则、标题、发现和缺口问题沿用最多一次局部修订，复检通过才进入发布。
- 既有 IOC、检测特征及上下文对象统一分类展示，同值保留一次并合并角色、证据和简短说明。原值和源码不改写。
- 上下文支持已知样本信息；报告审计由真实审计记录生成。未知、空或未运行状态不显示通过，底层 not_run/passed=true 也不会造成通过徽章。运行时测试填充已移除，manifest 保留空 test_fills。
- 原有预算、入口、输出命名、原子发布和失败诊断机制保持。文档与独立合成示例契约同步更新。

## 验证证据

- 工作区：`uv run --offline pytest tests -q -rs`：507 passed / 1 skipped。
- 跳过项：Windows 未授予符号链接创建权限；与修改前基线一致。
- 新增 37 项针对 1.1 的测试；先复现缺失功能或边界错误，再实施修正。包括一次修订、规则、自定义档位、证据状态、真实空值、指标去重、审计执行状态和全部可见文字位置的缺口检查。
- 独立复核指出的 IOC 说明等文字位置、代码 caption、未知审计状态及 method 类型问题均增加回归并修正。
- wheel 和 sdist 均在工作区外隔离导入 45 个模块，验证新资源及无模型独立编译、渲染；sdist 内全套测试同为 507 passed / 1 skipped。
- 11 个旧版示例输入与历史 report_coverage_20261027.json 均按字节核对未变；CSS 与新版源 skill 按字节一致。
- 全字段示例包含 16 个 id 与 16 个内部链接，空上下文示例包含 14 个 id 与 14 个内部链接；均无重复或失效锚点，内嵌 JSON 与模板数据一致，无外部资源加载。
- 两份示例真实模型请求均为 0，test_fills 均为空；唯一模板告警为演示中的 CUSTOM 规则需要人工复核，符合预期。
